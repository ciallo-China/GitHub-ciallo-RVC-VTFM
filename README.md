# GitHub-ciallo-RVC-VTFM
RVC声线转音（PC）
========================================
 RVC 声线转音（电脑版）使用介绍
 版本 v2.5.01.300 · 为大肥鱼打造
========================================

【这是什么】
RVC 声线转音是一款把普通声音/音频转换成指定角色声线的本地转换工具。
核心技术来源于开源的 RVC（Retrieval-based Voice Conversion，检索式语音转换）
项目，采用"特征提取 + 音高估计 + 声线合成"三阶段流程，全程在您自己电脑上
运行，不需要联网，音频不会上传到任何服务器。

【各功能的来源】
1. 转换引擎：基于开源 RVC 项目（含 ContentVec 音色特征模型、RMVPE 音高模型、
   Hubert 声纹模型），打包成便携式 Engine 文件夹，内置 Python 运行环境，
   打开即用，无需自己配置环境。
2. 声线包：Voice-LP 文件夹内置蔚蓝档案角色声线（星野、爱丽丝、白子、日奈、
   凯伊、芹香、才羽姐妹、高松灯等），由角色语音素材训练而成。
3. 界面主题：粉蓝 / 紫夜 / 薄荷三套配色，仿现代软件设置风格，支持自定义
   背景（纯色、渐变色、图片、视频）与粒子特效。
4. 快捷键与历史：转换快捷键可自定义；每次转换自动记录历史，便于回溯。
5. 手机配套：软件内置局域网模式，手机浏览器输入地址即可远程操作转音。

【怎么使用】
第一步：把要转换的音频放进 Audio-PA 文件夹（支持 mp3 / wav / m4a / flac 等）。
第二步：打开软件，在左侧选择想要的目标声线（点击头像卡片即可切换）。
第三步：按需调整参数：
   · 音调：+/-12 半音（男声转女声一般 +8 到 +12）；
   · 相似度：越高越像角色音色；
   · 保护：避免破音，一般保持默认；
   · 输出格式：wav 无损 / mp3 省空间；
   · 音高算法：RMVPE 更准（推荐），Harvest 更省内存。
第四步：点击"开始转音"，等待进度条走完（带日志显示当前阶段）。
第五步：转换结果自动保存到 Audio-RL/对应声线/ 文件夹，可直接打开试听。

【文件夹说明】
  Audio-PA   放输入音频
  Audio-RL   转换结果（按声线自动分类）
  Voice-LP   声线包（可自行添加新声线）
  Engine     转换引擎（勿删除）
  CRVC VTFM  程序本体

【常见问题】
· 转换慢？ 关掉后台大程序，或把音高算法换成 Harvest；
· 没识别到声线？ 确认 Voice-LP 里有包含 .pth 文件的角色文件夹；
· 想加新声线？ 把新角色的模型文件夹（含 .pth）复制进 Voice-LP 即可。
